02 Web Server & Component Responsibilities

Layer Software Role in PROMPT HRMS
Application Web Server Kestrel (.NET 8.0.34) Microsoft's built-in, cross-platform, high-performance HTTP server. Executes all C# API controllers, EF Core transactions, Dapper SQL queries, Swagger, and serves the compiled React SPA from /opt/prompt-hrms/wwwroot/.
Process Manager systemd (prompt-hrms.service) Runs Kestrel 24/7 as non-privileged user prompthrms, starts automatically on server reboot, and auto-restarts on failure within 10 seconds.
Reverse Proxy (Edge) Nginx (ea-nginx) + Apache (httpd) Terminates HTTPS/SSL via cPanel AutoSSL and proxies traffic for prompthrms.sandslab.com to http://127.0.0.1:5050/ without affecting any other cPanel websites or PHP/MySQL apps.
Database Engine SQL Server 2022 CU28 Stores all HRMS data, Global Corporate UI Settings (AppUiSettings), DataAuditLogs, UserInteractionLogs, and Hangfire / Integration Outbox queue tables.
Background Queue & Cron Hangfire + SQL Server Outbox Runs inside HRMS.API backed by SQL Server 2022 (no RabbitMQ/Erlang required). Powers PROMPT ERP GL & CRM sync with automatic retries & Admin Error Queue (Req 3.7.12), protected payslip email batches, biometric sync, daily document/probation expiry alerts, and scheduled reports.

04 Why This Architecture Works for Enterprise HRMS

Key Benefits:
  • Zero CORS Complexity: React UI and /api/v1/* share the exact same origin (https://prompthrms.sandslab.com).
  • Zero Conflict with Existing Server Apps: Other cPanel domains, PHP apps, and MySQL remain untouched.
  • 100% Cross-Platform Portability: The same HRMS.API build deploys seamlessly on AlmaLinux (Kestrel + Nginx/Apache), Windows IIS (ASP.NET Core Hosting Bundle), or Docker.
  • Fast Updates: Frontend-only UI changes copy straight into /opt/prompt-hrms/wwwroot/ with zero downtime; backend updates restart Kestrel in ~2 seconds.

05 Quick Operations Reference

# Frontend-only update (as prompthrms@earth, zero restart needed):
cd ~/repo && git pull origin main && \cp -rf HRMS/backend/publish-linux/wwwroot/. /opt/prompt-hrms/wwwroot/

# Full-stack update (backend + frontend, as root@earth):
su - prompthrms -c "cd ~/repo && git pull origin main" && \
\cp -rf /home/prompthrms/repo/HRMS/backend/publish-linux/. /opt/prompt-hrms/ && \
chown -R prompthrms:prompthrms /opt/prompt-hrms && systemctl restart prompt-hrms

# Live service & log checks (as root@earth):
systemctl status prompt-hrms --no-pager
journalctl -u prompt-hrms -n 30 --no-pager
curl -s https://prompthrms.sandslab.com/api/v1/health
