SQL Server 2022 Remote Connection Guide (SSMS)

Secure Encrypted SSH Tunnel Connection to UniGlobalHRMS on AlmaLinux 8.10 (earth)

Security Policy (Verified): TCP port 1433 remains closed to the public internet. All remote SSMS administration connects over an encrypted SSH tunnel using local port 14330 (preventing any conflict with local Windows SQLEXPRESS on port 1433).

01 Start the Encrypted SSH Tunnel (Windows PowerShell)

Open Windows PowerShell on your developer PC and run the command below (keep this window open while working in SSMS):

ssh -L 127.0.0.1:14330:127.0.0.1:1433 root@185.252.176.129
  • Type yes if prompted to accept the server's ED25519 host fingerprint on first login.
  • Enter the server root password. Once [root@earth ~]# appears, the tunnel is active.

02 Connect in SQL Server Management Studio (SSMS)

Open SSMS and configure the connection properties exactly as shown:

Click Connect. Object Explorer will display 127.0.0.1,14330 (SQL Server 16.0.4325.4 - UniGlobalHRUser) → Databases → UniGlobalHRMS.

03 Alternative Access Methods

  • WHM / cPanel Browser Terminal: Open WHM → Terminal and run: 
    sqlcmd -S localhost -U UniGlobalHRUser -C -d UniGlobalHRMS
  • Direct Static IP (Optional — Only If Required): Whitelist only your office static IP in WHM → CSF (csf.allow): 
    tcp|in|d=1433|s=<YOUR_OFFICE_STATIC_IP>
    Reload CSF with csf -r, then connect SSMS to <server-ip>,1433.

04 Troubleshooting Guide

Error 1225 (The remote computer refused the network connection):
  1. Always use 127.0.0.1,14330 in SSMS — do NOT use localhost,14330 (Windows resolves localhost to IPv6 ::1, which misses the IPv4 SSH tunnel).
  2. Confirm the PowerShell SSH window is still open and logged in.
  3. Verify SSH TCP forwarding is enabled on the server: sshd -T | grep allowtcpforwarding (must return yes).

Closing the Session: Disconnect in SSMS, then type exit in the PowerShell SSH window.
