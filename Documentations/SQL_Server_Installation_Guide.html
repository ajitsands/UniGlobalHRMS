Server & SQL Server 2022 Installation Guide

AlmaLinux v8.10 (cPanel/WHM) Zero-Disturbance Setup for prompthrms.sandslab.com

Isolation Guarantee: SQL Server 2022 runs on port 1433 (/var/opt/mssql) and PROMPT HRMS runs internally on 127.0.0.1:5050 (/opt/prompt-hrms). Existing MySQL/MariaDB (port 3306), PHP, Apache, and all other cPanel domains remain 100% untouched.

01 Pre-Flight Safety Check

free -h
df -h /
ss -tulpn | grep -E ':1433|:5050' || echo "Ports 1433 and 5050 are FREE"

02 Install SQL Server 2022 on AlmaLinux 8.10

curl -o /etc/yum.repos.d/mssql-server.repo https://packages.microsoft.com/config/rhel/8/mssql-server-2022.repo
dnf install -y mssql-server
/opt/mssql/bin/mssql-conf setup

Choose edition (2 Developer, 3 Express, or licensed Standard/Enterprise) and set a strong SA password.

Cap SQL Server Memory (Protects Existing MySQL & Websites)

/opt/mssql/bin/mssql-conf set memory.memorylimitmb 4096
systemctl enable --now mssql-server
systemctl restart mssql-server
systemctl status mssql-server --no-pager

03 Install sqlcmd & Create UniGlobalHRMS Database

curl -o /etc/yum.repos.d/msprod.repo https://packages.microsoft.com/config/rhel/8/prod.repo
ACCEPT_EULA=Y dnf install -y mssql-tools18 unixODBC-devel
echo 'export PATH="$PATH:/opt/mssql-tools18/bin"' >> ~/.bashrc
source ~/.bashrc
sqlcmd -S localhost -U sa -C -Q "
CREATE DATABASE UniGlobalHRMS;
GO
CREATE LOGIN UniGlobalHRUser WITH PASSWORD = 'YourStrongPasswordHere';
USE UniGlobalHRMS;
CREATE USER UniGlobalHRUser FOR LOGIN UniGlobalHRUser;
ALTER ROLE db_owner ADD MEMBER UniGlobalHRUser;
GO"

04 Install ASP.NET Core 8.0 Runtime & Verify Stack

dnf install -y aspnetcore-runtime-8.0
systemctl is-active mssql-server mysqld mariadb 2>/dev/null
dotnet --list-runtimes
sqlcmd -S localhost -U UniGlobalHRUser -C -d UniGlobalHRMS -Q "SELECT DB_NAME() AS CurrentDB, @@VERSION AS Version"

05 Isolated App Service (systemd) & Apache Reverse Proxy

mkdir -p /opt/prompt-hrms/uploads /opt/prompt-hrms/logs
useradd -r -s /sbin/nologin prompthrms 2>/dev/null || true
chown -R prompthrms:prompthrms /opt/prompt-hrms

Create /etc/systemd/system/prompt-hrms.service listening only on http://127.0.0.1:5050, then configure the per-subdomain Apache include at /etc/apache2/conf.d/userdata/ssl/2_4/prompthrms/prompthrms.sandslab.com/hrms_proxy.conf:

ProxyPreserveHost On
ProxyPass / http://127.0.0.1:5050/
ProxyPassReverse / http://127.0.0.1:5050/
RequestHeader set X-Forwarded-Proto "https"
/usr/local/cpanel/scripts/rebuildhttpdconf
/usr/local/cpanel/scripts/restartsrv_httpd

07 Automated Daily SQL Server Backup

mkdir -p /var/opt/mssql/backups && chown mssql:mssql /var/opt/mssql/backups
/opt/mssql-tools18/bin/sqlcmd -S localhost -U sa -P '<SA_PASSWORD>' -C -Q \
"BACKUP DATABASE [UniGlobalHRMS] TO DISK = N'/var/opt/mssql/backups/UniGlobalHRMS_$(date +%F).bak' WITH COMPRESSION, STATS = 10"
